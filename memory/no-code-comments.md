在 D:\ark\java 里**不要给代码写注释**——包括类头 javadoc、方法/字段 javadoc、行内 `//` 说明，以及注释掉的死代码和多余空行。新写的文件直接保持无注释，除非用户明确要求解释。

**Why:** 用户重复要求过（会话中"检查这个生物相关代码有没有注释 有就删了"，此前还有 commit `清理: 批量删除注释/文档头/注释掉的死代码及多余空行(无行为变更)`）。说明理由和"为什么这样写"对用户没有价值，反而每次都要再清一遍。

**How to apply:** 写新文件时不加任何注释；改动已有文件时也不要顺手补注释。需要向用户解释设计取舍时，写在回复正文里，不要写进代码。仓库现有代码本身注释密度就是 0，保持一致。
